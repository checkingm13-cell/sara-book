# Sara Book Publication - Next.js Enterprise Architecture

High-performance, edge-rendered academic book publishing portal for **Sara Book Publication (Ahmedabad, Gujarat)**, engineered with modern Next.js App Router, Tailwind CSS, and zero-LCP CSS 3D hardware acceleration.

---

## 🚀 Key Modules & Routing
- `/` - Homepage with Swiss Typography, Noma Bar Gestalt Hero Slate, and dynamic ISBN verification.
- `/book/[slug]` - Dynamic crawlable book showcase with Schema.org JSON-LD and automatic Google Scholar APA citations.
- `/calculator` - Real-time academic printing cost, royalty simulator, and UGC API score breakdown.
- `/publish` - Streamlined author manuscript proposal submission portal.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router + Turbopack)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **SEO & AI Engine Optimization**: Schema.org JSON-LD (`Publisher`, `Book`, `FAQPage`)
- **Documentation**: Obsidian Knowledge Vault in `doc-vault/`
